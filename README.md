# AZAZA Linux WiFi Expert (Real System Edition)

Профессиональный набор инструментов для диагностики Wi-Fi и сети на **Python** без единой заглушки или фальшивых данных.

## Ключевые возможности
1. **Строгая системная диагностика интерфейсов**:
   - Автоматическая проверка состояния сети по интерфейсам ядра ОС.
   - **Ошибки и предупреждения**: Приложение выдает предупреждения, если Wi-Fi отключен/отсутствует, если используется мобильный интернет (WWAN) или если активен VPN-тоннель (`tun`/`tap`/`wg`/`ppp`).
2. **Настоящий Wi-Fi сканер**:
   - Сканирование видимых беспроводных сетей через системные утилиты Linux (`nmcli`, `iwlist`).
   - Группировка одинаковых SSID и детальный просмотр по BSSID и каналам.
3. **Эластичный ICMP Пинг**:
   - Настройка размера пакетов (`-s`) и количества пакетов (`-c`) для точной диагностики задержки и потерь ICMP.
4. **LAN ARP & TCP Port Scanner**:
   - Чтение таблицы ARP ядра (`/proc/net/arp`) и реальные TCP-соединения сокетов.
5. **Внешние сетевые ресурсы**:
   - Подборка полезных ссылок на официальные реестры портов IANA, RIPE, калькуляторы CIDR и документацию RFC.
6. **Классический Linux-терминал**:
   - Интерфейс оформлен в стиле старых консольных шрифтов Linux (`Share Tech Mono`) с цветовой гаммой зелёного монохромного терминала.

---

## Запуск
- Работает на порту `3000` (`python3 main.py`). Поддерживает PWA для Android.

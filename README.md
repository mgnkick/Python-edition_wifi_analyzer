# Azaza NETwork Tool (Midnight Commander Edition)

Автономный профессиональный инструмент диагностики сетей и Wi-Fi для Linux и Android-смартфонов, оформленный в аутентичном терминальном стиле **Midnight Commander (MC)**.

Приложение полностью готово к синхронизации с GitHub и **автоматически компилируется в единый файл `.apk`** средствами GitHub Actions при каждом push или создании релиза.

---

## Возможности приложения
1. **Интерфейс Midnight Commander**:
   - Классическая синяя цветовая гамма (`#000084` / `#0000a8`), акценты циан и желтого.
   - **Строго одно главное меню на экране**, прокручиваемое по горизонтали.
   - Поддержка горячих клавиш `[1]`–`[8]` на физической клавиатуре.
2. **100% Автономные утилиты (без имитаций и внешних серверов)**:
   - **Контроль интерфейсов**: предупреждения, если отключен Wi-Fi, обнаружен мобильный интернет смартфона или активен VPN-туннель.
   - **Сканер Wi-Fi**: группировка по SSID с детальным просмотром точек доступа BSSID, каналов и мощности сигнала (RSSI).
   - **LAN ARP Соседи**: опрос таблицы `/proc/net/arp` и обнаружение устройств в подсети.
   - **Эластичный ICMP Пинг**: настройка размера пакета (`-s`) и количества пакетов (`-c`).
   - **Сканер TCP Портов**: многопоточная проверка открытых служб.
   - **Внешние замеры скорости**: быстрый доступ к проверенным сервисам (**Яндекс Интернетометр**, **2ip.ru**, Ookla).
3. **Двухрежимная автономная архитектура**:
   - **Режим Android APK**: приложение работает полностью автономно внутри Android WebView с прямым вызовом нативных API (`WifiManager`, `ConnectivityManager`, `/proc/net/arp`).
   - **Режим Python / Web**: приложение запускается локально командой `python3 main.py` на порту 3000.

## Автоматическая компиляция `.apk` на GitHub

В репозиторий интегрирован готовый сценарий GitHub Actions: `.github/workflows/build-apk.yml`.
Как это работает:
1. Вы отправляете код в ваш репозиторий GitHub (`git push`).
2. GitHub автоматически запускает виртуальную машину Ubuntu, настраивает Android SDK и выполняет сборку:
   ```bash
   ./gradlew assembleDebug
   ```
3. На выходе формируется **один готовый файл `AzazaNETworkTool.apk`**.
4. Готовый `.apk` доступен для скачивания во вкладке **Actions** -> последний запуск -> артефакт **AzazaNETworkTool-APK** (или во вкладке **Releases**, если вы добавите тег `v1.0.0`).

## Синхронизация с вашим GitHub репозиторием

Чтобы связать текущий проект с вашим GitHub репозиторием и запустить сборку:

```bash
# 1. Инициализация и добавление файлов (если еще не сделано)
git init
git add .
git commit -m "Init Azaza NETwork Tool with automated Android APK build"

# 2. Добавление удаленного репозитория GitHub
git remote add origin https://github.com/ВАШ_ЛОГИН/ВАШ_РЕПОЗИТОРИЙ.git

# 3. Отправка в GitHub (запустит компиляцию .apk)
git branch -M main
git push -u origin main
```

Чтобы выпустить релиз с автоматическим прикреплением `.apk`:
```bash
git tag v1.0.0
git push origin v1.0.0
```
После этого перейдите на GitHub во вкладку **Releases** и загрузите скомпилированный `AzazaNETworkTool.apk` прямо на смартфон.

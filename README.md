# АЗАЗА Linux WiFi Эксперт

Профессиональный инструмент сетевой диагностики на **Python** без заглушек и имитаций. Полностью русифицирован.

## Основной функционал
1. **Системный контроль интерфейсов**:
   - Автоматическая проверка состояния сети. Предупреждает, если Вайфай отключен, используется мобильный интернет или активен VPN-тоннель (`tun`/`tap`/`wg`/`ppp`).
2. **Сканер Вайфай сетей и BSSID**:
   - Сканирование реальных сетей через утилиты ядра Linux с группировкой по SSID и просмотром BSSID.
3. **Эластичный ICMP Пинг**:
   - Настройка размера и количества отправляемых пакетов.
4. **LAN ARP & TCP Port Scanner**:
   - Опрос таблицы соседей (`/proc/net/arp`) и проверка открытых портов.
5. **Внешние сервисы замера скорости**:
   - Вкладка со ссылками на внешние ресурсы. Приоритетные сервисы: **Яндекс Интернетометр** и **2ip.ru**, а также Speedtest, nPerf и Минцифры.
6. **Классический Linux-терминал**:
   - Оформление в стиле старых консольных шрифтов Linux.

---
Запуск на порту `3000` (`python3 main.py`).

# АЗАЗА :: Midnight Commander WiFi Expert (Автономное издание)

Профессиональный сетевой инструментарий для Linux и Android, оформленный в аутентичном визуальном стиле **Midnight Commander (MC)**. Работает полностью автономно на чистом Python 3 без вымышленных данных и сторонних библиотек.

---

## Особенности и функционал
1. **Стиль Midnight Commander (TUI)**:
   - Классическая синяя цветовая гамма (`#000084` / `#0000a8`), акценты желтого и циан.
   - Рамочные блоки с заголовками, оформление функциональных кнопок в стиле функциональных клавиш MC (`[1]`, `[2]`, ... `[8]`).
   - Поддержка горячих клавиш: клавиши `1`–`8` на клавиатуре мгновенно переключают разделы.
2. **Единое меню на экране**:
   - На единицу времени на экране отображается **строго одно основное меню** с кнопками, плавно пролистываемое по горизонтали. Никаких дублирующих боковых панелей или нижних дубликатов на смартфонах.
3. **100% Автономные утилиты без имитаций**:
   - **Контроль системных интерфейсов**: автоматическая проверка `/proc/net/dev` и `/sys/class/net`. Приложение выдает предупреждения, если отключен Wi-Fi, обнаружен мобильный интернет (сотовая сеть) или активен VPN-туннель (`tun`/`tap`/`wg`/`ppp`).
   - **Сканер Wi-Fi сетей**: сканирование через `termux-wifi-scaninfo`, `nmcli`, `iwlist` с группировкой одинаковых SSID и просмотром по BSSID. При отсутствии беспроводного адаптера честно сообщает о состоянии оборудования.
   - **Таблица соседей ARP**: прямое чтение `/proc/net/arp` с разрешением доменных имен хостов.
   - **Эластичный ICMP Пинг**: настройка размера пакетов (`-s`) и количества пакетов (`-c`).
   - **Многопоточный сканер TCP портов**: проверка реальных сокетов хоста.
   - **Таблица маршрутизации ядра**: парсинг `/proc/net/route`.
4. **Внешние ресурсы для замера скорости**:
   - Специальный раздел с прямыми ссылками. Приоритетные:
     - ★ **Яндекс Интернетометр** (ТОП-1)
     - ★ **2ip.ru (Тест скорости)** (ТОП-2)
     - Speedtest by Ookla, nPerf, Минцифры РФ, SpeedCheck.
5. **Автоматическая компиляция на GitHub**:
   - Настроены GitHub Actions в каталоге `.github/workflows/`:
     - `ci.yml`: автоматическая компиляция Python, проверка синтаксиса и тестирование эндпоинтов.
     - `build-apk.yml`: сборка и публикация релизного пакета / артефакта.

---

## Запуск приложения
```bash
python3 main.py
```
Сервер будет доступен по адресу `http://localhost:3000` (или через локальный IP на Android-смартфоне).
Также поддерживается установка в качестве PWA-приложения (Add to Home Screen).
